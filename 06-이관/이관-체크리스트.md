### 이관 순서 — 순서를 바꾸면 사이트가 끊긴다

```
1. 도메인 확정            → NEXT_PUBLIC_SITE_URL 값이 여기서 나온다
2. GA4 속성 생성(클라)    → 측정 ID 확보
3. Supabase 프로젝트 생성 → URL · anon key · service role key 확보
4. Vercel 환경변수 입력   → 3까지의 값을 전부 넣고 재배포
5. 도메인 연결 + 재배포   → og:url · canonical · sitemap 이 실주소로 바뀐다
6. Search Console · 서치어드바이저 등록 → sitemap 제출
7. Vercel · GitHub 소유권 이전
8. 하자보수 접근권 서면 확인 (아래 §4)
```

**5번 전에 6번을 하면 안 된다.** 아직 Vercel 도메인이 canonical 이라, 그 상태로 색인되면
실도메인으로 바꾼 뒤 중복 콘텐츠 정리를 다시 해야 한다.

## 2. 환경변수

Vercel > 프로젝트 > Settings > Environment Variables. **Production · Preview 양쪽에 넣는다.**
값의 형태와 주의사항은 `05-서비스-nextjs/.env.example` 에 주석으로 함께 있다.

| 키 | 값 출처 | 비우면 | 상태 |
|---|---|---|---|
| `NEXT_PUBLIC_SITE_URL` | 확정 도메인 | Vercel 프로덕션 도메인을 자동으로 씀 | 🔴 도메인 대기 |
| `NEXT_PUBLIC_GA_ID` | GA4 > 관리 > 데이터 스트림 > 측정 ID (`G-…`) | **gtag.js 를 아예 싣지 않음** — 계측 전부 중단 | 🔴 |
| `NEXT_PUBLIC_PLUUG_FORM_URL` | pluug > 폼 > 공유 링크 (**www 붙은 정규 주소**) | 문의 버튼이 죽음 | ✅ 입력됨 |
| `NEXT_PUBLIC_CHANNEL_PLUGIN_KEY` | 채널톡 > 채널 설정 > 보안 및 개발 | 채널톡 위젯 미노출 | ✅ 입력됨 |
| `NEXT_PUBLIC_UTM_SOURCE` | 고정값 `ai-builder-group` | `ai-builder-group` 으로 폴백 | ✅ |
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase > Settings > API | 어드민 미동작 | ⬜ 4단계 |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | 〃 | 어드민 미동작 | ⬜ 4단계 |
| `SUPABASE_SERVICE_ROLE_KEY` | 〃 | 서버 액션 미동작 | ⬜ 4단계 |

> 🔴 **`SUPABASE_SERVICE_ROLE_KEY` 에는 `NEXT_PUBLIC_` 을 붙이지 않는다.** 붙이는 순간
> 브라우저 번들에 들어가고, 그 키는 RLS 를 통째로 우회한다(NFR-12). 이름을 잘못 지은 것만으로
> DB 전체가 공개된다.

### 값이 들어갔는지 확인하는 법

```bash
# 배포본에서 GA 가 실제로 켜졌는지 (측정 ID 가 HTML 에 있어야 한다)
curl -s https://<도메인>/ | grep -o 'googletagmanager[^"]*'

# canonical 이 실도메인인지
curl -s https://<도메인>/ | grep -o '<link rel="canonical"[^>]*>'

# 색인 제외가 지켜지는지
curl -s https://<도메인>/robots.txt
curl -s https://<도메인>/submit | grep -o 'name="robots"[^>]*'
```

## 3. 이관 전 반드시 해결 — 🔴 발행 블로커

| # | 항목 | 왜 블로커인가 | 어디를 고치나 |
|:--:|---|---|---|
| 1 | **개인정보처리방침 빈칸 5곳** | 법적 고지다. 임의로 채우면 안 되고, 비운 채 발행해도 안 된다 | `05-서비스-nextjs/app/privacy/page.tsx` — 화면에 라임색 `[[ ]]` 로 떠 있다. 시행일 · 보유 기간 · 사업자 상호 · 보호책임자 성명/직위 · 연락처 |
